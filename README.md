# Nexora Premium Market

Nexora is a mobile-first shopping web app with a premium purple storefront, Express API, and SQLite persistence.

## Features

- Product browsing with exact category filtering
- Search screen with live suggestions and recent searches
- Product details, variants, specifications, reviews, Q&A, and related products
- Wishlist and cart quantity controls
- Authenticated checkout and user-scoped orders
- Delivery address management
- Premium offers, notifications, profile, settings, and responsive bottom navigation
- SQLite-backed product, cart, wishlist, address, and order data
- Render configuration with persistent disk support for SQLite

## Requirements

- Node.js 18 or newer
- npm

## Local setup

```powershell
npm ci
Copy-Item .env.example .env
npm start
```

Open [http://localhost:3000](http://localhost:3000).

For development, `npm run dev` starts the same server.

## Environment variables

Use `.env.example` as the template. Never commit `.env` or production secrets.

- `PORT`: HTTP port; defaults to `3000`
- `NODE_ENV`: `development` or `production`
- `ADMIN_KEY`: required for admin API access
- `DATABASE_PATH`: SQLite file path; defaults to `./nexora.sqlite`

## API overview

- `GET /healthz`
- `GET /api/products`
- `GET /api/products?category=Fashion`
- `POST /api/auth/signup`
- `POST /api/auth/login`
- Authenticated cart, wishlist, address, and order endpoints

## Render deployment

`render.yaml` defines the production service:

- Build command: `npm ci`
- Start command: `npm start`
- Health check: `/healthz`
- SQLite path: `/var/data/nexora.sqlite`
- Persistent disk mounted at `/var/data`
- `ADMIN_KEY` generated by Render

The SQLite database is intentionally excluded from Git. Production data must live on the Render persistent disk.
